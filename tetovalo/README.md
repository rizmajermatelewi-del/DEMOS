# Fekete Tinta: flash lap és árbecslés

Bemutató projekt, saját kezdeményezés. Nem élő vállalkozás, minden adat kitalált.

- **Flash lap:** kész minták, mindegyik egyszer foglalható, 18 év alatt nem (`claimProblems`).
- **Árbecslés:** hely, méret, stílus alapján ársáv, idő, alkalmak (max. 4 óra), fájdalom, gyógyulás (`estimate`).
- **Konzultáció** referenciaképpel, csak helyi előnézet.

Vanilla JS + Vite. Tesztek: `npm test`. Fotók: Unsplash. Betűk: Pirata One, Space Grotesk (SIL OFL).
